## Запуск

Python 3.12. Из корня проекта:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

В `experiments.ipynb` выбрать это окружение, **перезапустить ядро и выполнить все ячейки**.
Данные скачиваются автоматически. В `.cache/` хранятся данные и рекомендации; в Git они не входят.

## Содержание

- Очистка, EDA и временное разбиение: train до 22.04.2022, validation до 01.05, затем test (UTC).
- Пять моделей с нуля в `models/`; 36 настроек выбираются только по validation, seed=42.
- NDCG@10 и Recall@10 по единому каталогу, без уже показанных видео. Переобучения на validation нет.
- Итоговые таблицы и графики — в ноутбуке и `reports/`.

Структура проекта:

```text
experiments.ipynb       — выполненный эксперимент
models/                — реализации пяти моделей
features.py, protocol.py — признаки и разбиение данных
evaluation.py, experiment_utils.py — метрики и подбор параметров
reports/               — итоговые таблицы и графики
tests/                 — тесты и независимый аудит
```

Проверки после выполнения ноутбука:

```bash
python -m unittest discover -s tests -v
python tests/audit_results.py
```

Лидер — **EASE**: NDCG@10 **0,05497**, Recall@10 **0,08603** на 14 356 test-пользователях.
Истории ограничены пулом Pure, выдача смещена прежней системой; холодный старт не оценивается.
